# 第11课-贪吃蛇与面向对象

**主题**：贪吃蛇与面向对象

**当堂验收**：能动、能吃 1 次、能撞墙死。

**说明**：课堂讲义与本课数据同目录；课后练习使用题面指定的文件。从该文件夹启动内核。

游玩 python3 snake.py；验收 python3 snake.py --demo 或 python3 experiment.py
## 本课文件

| 文件 | 用途 |
|------|------|
| `chapter11_贪吃蛇与面向对象_学生讲义.ipynb` | 课堂讲义：知识点、案例、即时练习、综合练习 P1 |
| `chapter11_贪吃蛇与面向对象_课后练习.ipynb` | 课后练习：P1、P2 必做，P3 选做 |
| `snake.py` | 命令行贪吃蛇；课堂后半可 import |
| `experiment.py` | 验收脚本，调用 snake.run_demo |

运行验收版：

```bash
python3 experiment.py
```
