# 课次 L10 贪吃蛇与面向对象

**对应源章** Ch11

**建议学时** 6（三次 90 分钟）。路径 B 整课跳过。

## 目标

**知识目标**

1. 了解二维结构是"列表的列表"在空间上的用法
2. 了解类与实例、类属性与实例属性、构造方法
3. 了解游戏主循环：读输入 → 更新坐标 → 判定死亡 → 刷新

**能力目标**

1. 能生成场地并在坐标上写入蛇与食物
2. 能用三个类（或等价的一组类）描述场地、蛇、食物
3. 能跑通至少"移动一格、吃到一次食物、撞墙结束"

**素养目标**

1. 体会对象是把数据与行为打包，以便主循环保持短

**前置准备**

1. 函数调用熟练
2. 嵌套列表熟练
3. 教师已决定运行载体：Jupyter 多帧打印，或 Terminal 运行 py

## 小节合并

14 个 md 压成三段课，禁止按 md 一周一节。

1. range、二维表、生成区域/蛇/食物（空间）
2. 类的比喻、属性、构造、把三者搬进 class
3. 方向、死亡、移动、刷新（主循环）

Cat 例子最多 15 分钟，随后必须回到蛇。

## 时间盒（3×90 分钟）

**第一次：空间**

| 分钟 | 内容 |
|------|------|
| 0–15 | range；一维下标 |
| 15–50 | 双重循环建二维表并打印 |
| 50–85 | 写入蛇坐标与食物坐标 |
| 85–90 | 打印一帧场地 |

**第二次：类**

| 分钟 | 内容 |
|------|------|
| 0–20 | 模具与玩具；两只 Cat |
| 20–40 | 类属性 vs 实例属性（改一只不影响另一只） |
| 40–85 | Snake / Map / Food 构造与方法骨架 |
| 85–90 | 用类再打印一帧，效果与第一次相同 |

**第三次：能玩**

| 分钟 | 内容 |
|------|------|
| 0–25 | 方向与下一格坐标 |
| 25–50 | 撞墙、咬自己、（可选）不许回头 |
| 50–80 | 移动、吃食物变长、循环 |
| 80–90 | 能玩即可；美化课后 |

## 实验

必做：二维表、写入符号、两只实例、三类骨架、移动一格、一种死亡、吃到一次食物。选做：清屏、加速、记分。

## 怎么串

向学生承认：本课离开游戏数据。它的职务是 class，不是再分析 Steam。主循环与 L03 的 for 不同：这是"直到死亡才停"的 while 直觉，若源讲义用 for 刷新，跟讲义走，不另开 while 理论课，除非学生先问。

## 卡点

| 现象 | 处置 |
|------|------|
| Jupyter 里清屏无效 | 改打印分隔线；或换 Terminal |
| 蛇身用单个坐标而非列表 | 吃食物无法变长，第一次课就用列表装身体 |
| 类写完又退回全局变量 | 第三次课禁止新的全局列表 |
| 死亡条件一次讲四个 | 先撞墙，咬自己课后 |

## 当堂验收

第三次课现场玩 30 秒：能动、能死。不要求完整游戏体验评分。

## 接口

路径 A 下一课回到模块，与蛇无关。不要布置"用 class 重构 Steam 分析"。

## 路径裁剪

- 路径 B：整课删除，学时还 L03/L07/L11。
- 路径 C：本课可扩到 9 学时，第三次拆成死亡与刷新两周。
- 48 学时仍不够三次：删 Cat，第二次直接上蛇的类。
