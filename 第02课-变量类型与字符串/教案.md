# 课次 L02 变量、类型与字符串

**对应源章** Ch02（experiment2-1 至 2-9）

**建议学时** 3

## 目标

**知识目标**

1. 了解赋值、覆盖、命名规则
2. 了解 int、float、str 以及 int() / float() / str() 在做什么

**能力目标**

1. 能把一次计算结果存起来再参与下一次运算
2. 能解释 int(3.9) 为什么是 3
3. 能用 + 拼接两段文字，并能读懂数字加字符串的 TypeError

**素养目标**

1. 开始用"这个值是什么类型"来解释报错，而不是重敲一遍

**前置准备**

1. 完成 L01：能运行代码块
2. 源任务四（快捷运算）按选做处理

## 小节合并

课堂上两段半：

1. 任务 1–3：取名、规则、改值（一个"盒子"故事讲完）
2. 任务 5–6：整数、浮点、转换（含破坏性 int("3.9") 或 int(3.9)）
3. 任务 7–9：字符串与拼接

任务 4 的 += 口头对照 `data = data + 1`，不占独立实验。

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–10 | 回钩：L01 的 2+9 跑完就消失，怎样留给下一格用 |
| 10–35 | 赋值、非法名报错、二次赋值 |
| 35–60 | int / float、除法、int(3.9)、float("8.8") |
| 60–80 | 引号、拼接、"8"+"8" 对 8+8、数字+字符串报错 |
| 80–90 | 收束：类型绳子第一句写上黑板 |

## 实验

必做：赋值与覆盖、非法名、int(3.9)、拼接、TypeError。选做：+=。破坏性：关键字当变量名、混加。

## 怎么串

用"身高 180 以后还要拿来算 BMI"这种留下名字的需求，不要用"变量是计算机科学概念"开场。字符串晚于数字出场：先让盒子里装数，再发现盒子里也可以装字。拼接放在最后，是为 L03 列表里既有名字又有评分做铺垫——同一行记录里本来就混着两种类型。

## 卡点

| 现象 | 处置 |
|------|------|
| 中文变量名能跑，学生滥用 | 允许但不鼓励；本课标识符用英文 |
| 以为 int(3.9) 四舍五入 | 对比 round，只点一句，不展开 |
| 引号用了中文 “ ” | 与全角加号同样处理 |
| float("8.8 分") | 留到 L08 再系统洗字符串，这里只说明"必须是纯数字文本" |

## 当堂验收

现场提问三选一：覆盖后旧值在哪；int(3.9)；"1"+1 会怎样。答不出的留下补跑破坏性实验。

## 接口

学生 notebook 里应有：一个 float 转换例子、一个 TypeError 例子（可保留报错格）。L03 会把游戏评分当字符串读出来。

## 路径裁剪

- 有基础：只做 TypeError 与 int 截断，30 分钟结束，余时预读列表字面量。
- 紧凑班：与 L01 合并为 4 学时，砍 += 与长字符串任务。
