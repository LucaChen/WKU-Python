# 课次 L11 模块与日期时间

**对应源章** Ch12

**建议学时** 3

## 目标

**知识目标**

1. 了解 import 的几种写法以及为何全班要锁一种
2. 了解 datetime 对象与 strptime / strftime 的方向（文本 → 对象 → 文本）

**能力目标**

1. 能把一列杂乱日期解析成 datetime
2. 能统一输出格式并比较先后或计算时长

**素养目标**

1. 遇到日期不要用随手切片硬解析月日；优先标准库

**前置准备**

1. 会写 for 与函数
2. **开课前锁定数据集**：疾病日数据或白宫访客，不要两套都发
3. calendar 模块不讲

## 小节合并

三段：为什么要模块 + import 写法锁定 → 统一格式（原上/下合并）→ 比较时长（原分析上/下合并）。

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–15 | csv 其实早就在用模块；三种 import 投影，锁定一种写法 |
| 15–55 | strptime 失败样例先跑；循环解析一列；strftime 统一 |
| 55–80 | 最早最晚、时长；max/min 用在 datetime 上 |
| 80–90 | 收束：标准库与自己写循环的分工 |

## 实验

必做：三种 import 各尝一次后锁定、strptime 整列、strftime、最早最晚。破坏性：格式串与数据不一致导致的 ValueError。

## 怎么串

这是数据分析主线的收束：L08 洗字符串，L11 洗时间。强调模块不是"高阶选修"，而是 L03 读 csv 时已经发生过的事。若路径 B 跳过了蛇，本课承担"本学期第二个综合实验"的心理位置，时间盒可扩到 4 学时加小报告。

## 卡点

| 现象 | 处置 |
|------|------|
| datetime 模块与类同名绕晕 | 只允许一种 import，写在黑板顶格 |
| 时区、locale | 本课不涉及 |
| 空日期 | 跳过或记 None，不讲 try 体系也可，用 if 跳空串 |
| 源讲义两套故事混着读 | 教师提供一份改过的入口说明，禁止学生自己两边对 |

## 当堂验收

统一格式后的 5 行输出 + 一个时间差。格式串写错的当场对照失败行。

## 接口

无后续必修课。考核若含上机，可出"统一日期并数某年记录数"，不得出贪吃蛇算法证明题（除非路径 C 明确考蛇）。

## 路径裁剪

- 任何认真声称"会用 Python 做分析"的班不建议整课删除。
- 可缩到 2 学时：砍三种 import 对比，直接锁定 from datetime import datetime。
