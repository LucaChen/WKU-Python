# 课次 L08 Steam 字符串清洗

**对应源章** Ch09

**建议学时** 3

## 目标

**知识目标**

1. 了解字符串方法 replace，以及大小写统一在合并类别时的作用
2. 了解"看起来像数的字段"去逗号、去单位之后才能 int/float

**能力目标**

1. 能打开 steam.csv 并对照 header 说出分析要用的列
2. 能清洗分类或平台字段，使 == 或 in 比较稳定
3. 能从带杂质的评价数字段得到整数

**素养目标**

1. 换数据集先认列，再谈方法；不把移动游戏的下标套到 Steam 上

**前置准备**

1. L06 函数可复用
2. steam.csv 已发放；教师自己先跑通 header

## 小节合并

课堂上三段：认列（含读取）→ replace 与大小写、分类清理 → 评价数转数值 + 复杂字段解析（上/下合并，做到能算为止）。

capitalize 不单独成段，跟在 replace 后面 8 分钟。

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–20 | 认列仪式：打印 header、两行样例、与 mobile 表对比"脏在哪" |
| 20–50 | replace 去脏词/空格；平台大小写合并前后的频数对照 |
| 50–80 | 去逗号转 int；解析一个带单位或括号的字段 |
| 80–90 | 收束：清洗是为了 L09 的年份与档位 |

## 实验

必做：认列、replace、平台统一、评价数转 int、一个复杂字段。破坏性：未清洗就 int() 看 ValueError。

## 怎么串

字符串方法迟到这里才登场，是因为移动游戏表相对干净。教师应明确说：不是"现在开始学字符串"，是"字段拒绝被计算了"。L09 的切片会把评价数变成档位，本课必须先得到真正的数字或数字字符串。

## 卡点

| 现象 | 处置 |
|------|------|
| 沿用 L03 的列下标 | 停课认列，把 Steam 下标写死在黑板 |
| replace 没接回变量 | 提醒字符串不可变，必须赋值 |
| 只洗了样例五行以为全表洗了 | 循环里洗，再抽查 len 与频数 |
| 复杂字段每人字段不同 | 教师指定同一列，禁止自由发挥拖垮课堂 |

## 当堂验收

同一列清洗前后各 print 3 行；int 转换成功的计数。认不出列名的不能进入 L09。

## 接口

清洗函数或清洗后的列表留给 L09。列下标写在 notebook 顶部常量区。

- 路径 B 32 学时：与 L09 连成 4 学时一次过。
