# 第06课-函数入门

**主题**：函数入门

**当堂验收**：换一个列下标，同一套抽列 + 频数函数能得到新的频率表。

**说明**：课堂讲义与本课数据同目录；课后练习使用题面指定的文件。从该文件夹启动内核。

课堂讲义与 `mobile_game_info.csv` 同目录；课后练习与 `googleplaystore.csv` 同目录。不要重写第5课四步，把它缩进到 `def` 里。`return` 不是 `print`。本课 CSV 可能带 UTF-8 BOM，打开课堂文件时使用 `encoding="utf-8-sig"`。
