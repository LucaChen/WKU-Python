# 课次 L06 函数、返回值与作用域

**对应源章** Ch06 + Ch07

**建议学时** 4（两次 90 分钟）

## 目标

**知识目标**

1. 了解 def、参数、默认参数、return、元组拆包
2. 了解局部变量与全局变量不是同一格盒子
3. 了解内置名被覆盖之后会发生什么

**能力目标**

1. 能写出抽取任意列的函数和频数函数
2. 能在一个函数里调用另一个函数得到频率表
3. 能拆包两个返回值，并能指出函数内赋值没有改掉外面的同名变量

**素养目标**

1. 把"重复出现三次的循环"视为应当收拢的信号，而不是多复制几次

**前置准备**

1. L05 四步频数已跑通
2. 不要求预先知道"作用域"这个词

## 小节合并

第一次课：认识函数 + 平方（降温）→ 抽列 → 频数函数 → 两参数 → 函数调函数。

第二次课：覆盖 print 的惨案 → 默认参数 → 多返回与元组 → 全局/局部。Ch07"和或差"例子缩成一个 return a, b。

## 时间盒（2×90 分钟）

**第一次**

| 分钟 | 内容 |
|------|------|
| 0–15 | 平方函数：有来有回，print 在函数里 vs return |
| 15–50 | 抽列函数；换下标立刻得到名字列或评分列 |
| 50–80 | 把 L05 四步贴进 def；函数调函数 |
| 80–90 | 对比：没有函数时 notebook 有多长 |

**第二次**

| 分钟 | 内容 |
|------|------|
| 0–20 | 把自定义函数命名为 print 再调用真正打印 |
| 20–40 | 默认参数：列下标默认评分列 |
| 40–65 | return 两个值、type 是 tuple、拆包 |
| 65–85 | 函数内 x=1，外面 x 仍是旧值 |
| 85–90 | 预告 L07：读取、去重都要变成函数 |

## 实验

必做：square、抽列、频数函数、函数调函数、覆盖 print、默认参数、拆包、局部赋值。破坏性：覆盖 print、局部/全局。

## 怎么串

平方只为降低恐惧，真正的项目函数是抽列和频数。教师若把第一次课耗在数学函数上，第二次课的作用域会来不及，L07 集成会崩。return 与 print 的差别必须在平方例子里打透：L07 学生最爱在清洗函数里 print 却以为返回了表。

## 卡点

| 现象 | 处置 |
|------|------|
| 写了 def 从不调用 | 投影"定义不是运行" |
| 忘记 return | 调用处得到 None |
| 参数名与列名混为一谈 | 参数叫 index，列名仍在 header |
| 内核里残留被覆盖的 print | 重启内核，当作第二次破坏性实验 |

## 当堂验收

调用一行 extract(body, 2) 得到评分列；调用频率函数得到与 L05 一致的字典。第二次课问：函数里的 x 改了，外面的 x 是多少。

## 接口

抽列、频数、读取（若已封装）三个函数必须出现在学生文件里，L07 禁止重写这三块逻辑，只允许新增清洗函数。

## 路径裁剪

- 32 学时：平方 8 分钟；和或差删除；两次课压成一次 3 学时，优先保抽列、频数、作用域、覆盖内置。
- 路径 C：本课不裁，后面蛇要用方法，先把函数调用练顺。
