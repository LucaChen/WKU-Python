# 课次 L01 环境与第一次计算

**对应源章** Ch01（notebook 为主，README 任务列表仅作对照）

**建议学时** 3（一次 90 分钟 + 机房机动；路径 A 可排一整周的 3 学时连堂）

## 目标

**知识目标**

1. 了解 Jupyter 的代码块、内核、保存与重启不是同一件事
2. 了解表达式、print、注释在本课中的职责

**能力目标**

1. 能新建 ipynb，用 Shift+Enter 跑通四则运算
2. 能说明"不写 print 时界面往往只露出最后一个结果"

**素养目标**

1. 建立先猜结果再运行的习惯，而不是把编程当成抄字

**前置准备**

1. 学生账号或本机 Jupyter 已能打开
2. 教师机与学生同一套界面（云或本地，开课前锁定）
3. 不要求任何编程经验

## 小节合并

源 README 写 6 个任务，notebook 为 5 个。课堂上三段：

1. 界面：四块区域、新建文件夹、新建 ipynb、Markdown 与 Code 切换
2. 计算：1+1、多块运行、重启内核再跑全本
3. 控制输出：print、注释、乘除

"让多行代码在一行执行"不单独占段，需要时用分号当彩蛋，不作为考点。

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–15 | 登录彩排。有人打不开时不要开始讲语法 |
| 15–35 | 界面与新建文件。教师慢速点一遍，学生必须亲手建自己的文件夹 |
| 35–55 | 1+1、2+9 先猜后跑；两块加法；重启内核 |
| 55–75 | print 混用、注释掉一行、乘除 |
| 75–90 | 收束三句 + 下节预告"给结果起名字" |

## 实验

必做：新建文件、1+1、重启内核、print 混用、注释、先猜后跑。破坏性：注释后发现结果变了。

## 怎么串

不要开场讲"Python 是什么语言"。开场只问：小学算术能不能让机器代劳。算通了再说：后面几千行游戏数据，也是一次一次让机器代劳。点到 TapTap / Steam 主线即可，不展开 csv。

乘除放在最后，是为了在 L02 遇到 3/2 变成 1.5 时有记忆点。若课堂只做了加法，L02 的浮点会显得从天而降。

## 卡点

| 现象 | 处置 |
|------|------|
| 云账号进不去 | 立即切本地备用，不空耗 |
| 点了运行没反应 | 看是否停在 Markdown 块；切到 Code |
| 重启后数字"没了" | 这是教学内容，不是故障 |
| 学生用全角 ＋ | 当场对比半角 + |

## 当堂验收

每人交一张截图或现场看：自己的 ipynb 里有一行 print(2+9) 且有输出。不收书面作业。

## 接口

带着"会运行代码块"来上 L02。不必保存算术结果。

## 路径裁剪

- 有编程基础：15 分钟界面 + 10 分钟 print/注释，立刻发 csv 预览，但不讲 reader。
- 路径 B/C：本课不裁。
