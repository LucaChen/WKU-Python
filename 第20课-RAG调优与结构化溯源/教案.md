# 课次 L20 RAG 调优与结构化溯源

**对应阶段** 阶段四 · 任务三 3.2 / 25分

**建议学时** 3

## 目标

**知识目标**

1. 说明 BM25 + 向量为何要混合
2. SourcedAnswer 必须带 chunk_id 与 quote
3. 越界问题返回 FallbackResponse

**能力目标**

1. 能对比两款 Widget 并引用至少两个文档
2. 能拒绝天气类越界提问

**素养目标**

1. 把模型当不可靠组件：接口、Schema、熔断、溯源缺一不可

**前置准备**

1. 第 19 课流水线可用

## 当堂不讲

- 微调 LLM、商业 Rerank API

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–15 | 命中不准时先调检索再怪模型 |
| 15–55 | 基础单文档 + 进阶跨文档 |
| 55–80 | 高难：天气问题走 fallback |
| 80–90 | 25 分评分对照与学期收束 |

## 实验

必做：讲义案例 + 综合练习 P1。破坏性：超时、校验失败、死循环、越界提问（按课次出现）。

## 卡点

| 现象 | 处置 |
|------|------|
| 有文本就算溯源 | 必须有 chunk_id 与原文片段 |
| 越界仍拼答案 | OUT_OF_CORPUS 关键词直接兜底 |
| 跨文档只引用同一 md | 对比题至少两个 doc_id |

## 当堂验收

单文档带 chunk_id 溯源；跨文档聚合；越界提问返回 FallbackResponse。

教学运行时：`agent_lab/`。验收：`python3 experiment.py`。
