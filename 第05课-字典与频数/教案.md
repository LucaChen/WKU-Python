# 课次 L05 字典与频数

**对应源章** Ch05

**建议学时** 3

## 目标

**知识目标**

1. 了解字典由键值对组成，用 in 判断键是否存在
2. 了解"先判断再 +1"是频数表的固定步伐

**能力目标**

1. 能统计某一列每个取值出现多少次
2. 能把计数换成百分比并粗略校核总和
3. 能在键不存在时避免 KeyError

**素养目标**

1. 统计之前仍要沿用 L04 的清洗意识：脏类型名会变成一堆近似键

**前置准备**

1. 会写 for + if
2. 不要求事先背字典语法

## 小节合并

课堂上两段：

1. 建字典、取值、键值对、in、更新（一次讲完"计数器字典"）
2. 百分比频率；min/max 与分箱作为选做

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–10 | 回钩：每个类型一个变量 count_rpg、count_stg……类型一多就崩 |
| 10–45 | 空字典、in、d[k]=d[k]+1、故意取不存在的键 |
| 45–70 | 百分比；抽查某一类手算对照 |
| 70–82 | 选做：min/max 或下载量分箱，超时直接跳 |
| 82–90 | 收束：频率表步伐写成四步板书 |

四步板书：建空字典 → 循环 → 键不在则置 0 → 键对应值 +1。

## 实验

必做：分级计数、KeyError、百分比。选做：min/max、分箱。破坏性：KeyError。

## 怎么串

字典的职务不是"一种新的数据结构介绍"，而是 L04 筛完之后问"各类有多少"。L06 会把这四步收成函数；本课必须让四步出现在学生自己的格子里，函数才不是空壳。

## 卡点

| 现象 | 处置 |
|------|------|
| 用列表下标当键的直觉去写 d[0] | 打印 d.keys() |
| 键名带空格导致两个近似键 | 为 L08 replace 预告，本课先 print 出奇怪的键 |
| 百分比用整数除法 | 与 L02 浮点绳子勾连 |
| 先 +1 再判断 in | 必现 KeyError，正好用破坏性实验 |

## 当堂验收

一份类型频率字典 + 百分比。助教看 keys 是否像类型名，而不是看有没有花括号。

## 接口

四步频数代码原样保留。L06 要求"不要重写逻辑，把这四步缩进到 def 里"。

## 路径裁剪

- 路径 B 32 学时：删分箱与 min/max。
- 不可删 in 与 +1 步伐。
