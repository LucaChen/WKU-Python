# 课次 L19 RAG 检索流水线

**对应阶段** 阶段四 · 任务三 3.1 / 15分

**建议学时** 3

## 目标

**知识目标**

1. 按段落分块并赋予 chunk_id
2. 把检索挂成 Agent 可调用的 Tool
3. 抽检续航问题命中手册

**能力目标**

1. 能解释 doc_id::idx
2. 能把 hits 放进 Tool 的 ResultSchema

**素养目标**

1. 把模型当不可靠组件：接口、Schema、熔断、溯源缺一不可

**前置准备**

1. 第 17–18 课

## 当堂不讲

- Faiss GPU、百万级向量运维

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–15 | 为何不能把整本手册塞进 Prompt |
| 15–55 | chunk → Retriever → Tool |
| 55–80 | 命中率抽检：续航 / 48 小时 |
| 80–90 | 15 分评分对照 |

## 实验

必做：讲义案例 + 综合练习 P1。破坏性：超时、校验失败、死循环、越界提问（按课次出现）。

## 卡点

| 现象 | 处置 |
|------|------|
| 中文按空格分词 | 教学 tokenize 使用汉字 bigram |
| Agent 直接编答案 | 本课强制走 rag_search Tool |
| 课后读错目录 | 课后用本课 kb/，不要混用讲义变量 |

## 当堂验收

知识库完成分块入库；Retriever 封装为 Tool 并可被调用；续航类问题命中手册切片。

## 接口

教学运行时：`agent_lab/`。验收：`python3 experiment.py`。
