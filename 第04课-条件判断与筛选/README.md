# 第04课-条件判断与筛选

**主题**：条件判断与筛选

**当堂验收**：组合条件平均分 + 高中低分计数守恒。

**说明**：课堂讲义与 `mobile_game_info.csv` 同目录；课后练习与 `googleplaystore.csv` 同目录。从该文件夹启动内核。`isAndroid` 在文件里是字符串 `TRUE` / `FALSE`。

## 本课文件

| 文件 | 用途 |
|------|------|
| `chapter04_条件与判断_学生讲义.ipynb` | 课堂讲义：知识点、案例、即时练习、综合练习 P1 |
| `chapter04_条件与判断_课后练习.ipynb` | 课后练习：P1、P2 必做，P3 选做 |
| `mobile_game_info.csv` | 课堂数据，266 条游戏记录 |
| `googleplaystore.csv` | 课后数据，50 条应用记录 |
| `experiment.py` | 验收脚本 |

运行验收版：

```bash
python3 experiment.py
```
