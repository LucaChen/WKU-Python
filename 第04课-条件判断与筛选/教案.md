# 课次 L04 条件判断与筛选

**对应源章** Ch04

**建议学时** 3

## 目标

**知识目标**

1. 了解比较运算的结果是布尔值
2. 了解 if / elif、and / or 在筛选行时的含义

**能力目标**

1. 能按平台或类型过滤行并计算子集平均分
2. 能写出"类型为 RPG 或策略，且非安卓"这类组合条件
3. 能用 if elif 给高分档打标，并使三类计数之和等于总行数

**素养目标**

1. 筛选规则必须说得出来：留下谁、扔掉谁，不能只交一个数字

**前置准备**

1. L03 的 body 能循环
2. 已知道评分列下标并会 float

## 小节合并

课堂上三段：

1. if + 布尔 + != + 比较运算（"问一句，得到 True/False"）
2. and / or + 组合平均分
3. 打标 + elif 高分档

源 orSearch 标题写"同时满足"容易与 and 混淆，教师口头必须纠正：or 是满足其一。

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–8 | 回钩：全表平均分掩盖了"只看 RPG" |
| 8–30 | 筛安卓；print(row[k] == 'TRUE')；!= 对照 |
| 30–60 | RPG 平均；and；or；组合题 |
| 60–82 | elif 三档打标，核验计数和 |
| 82–90 | 学生用一句话写出本课筛选规则 |

## 实验

必做：安卓筛选、布尔打印、RPG 平均、and、or、组合平均、elif 计数守恒。破坏性：and 写成 or 看行数暴涨。

## 怎么串

条件不是新章节，是 L03 循环身体里多写的一句话。强调：for 负责"每一行"，if 负责"要不要"。组合条件为 L05 字典分流、L07 语言+平台双过滤打样。

## 卡点

| 现象 | 处置 |
|------|------|
| 用 = 比较 | 当场 SyntaxError 或意外赋值，改 == |
| 字符串 'TRUE' 与布尔 True 混用 | 打印 type(row[k])，跟文件里真实值走 |
| or 理解成互斥 | 用两行样例：只满足左、只满足右、都满足 |
| elif 漏掉中间档 | 用计数守恒揭穿 |

## 当堂验收

组合条件平均分 + 口头规则。数字对但说成"筛了安卓 RPG"而代码是 or 的，记为说不清。

## 接口

同一 notebook 续写。L05 会把"每个类型多少个"从一串 if 改成字典。

## 路径裁剪

- 紧凑班：打标与 elif 留一个即可。
- 不可跳过组合条件题。
