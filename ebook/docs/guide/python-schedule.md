## 1. 这门课在干什么

用 Python 读表、清洗、统计，完成对**移动游戏市场**与 **Steam 目录**的分析；第 11 课用命令行贪吃蛇把**类和二维结构**跑通；第 12 课用标准库处理**日期时间**。

源讲义把 8 个主项目拆成 12 个实验仓（其中 4 个是上/下篇）。本课表按**12 节课上课**，按**8 个主项目备课**，按**12 个文件夹发材料**。

```text
┌── 数据分析主线 ─────────────────────────────────────────┐
│ 第1–2课 环境/变量 → 第3课 读表循环 → 第4–5课 筛选/频数   │
│ → 第6–7课 函数 → 第8课 游戏市场综合 → 第9–10课 Steam     │
│ → 第12课 模块与日期时间                                   │
└──────────────────────────────────────────────────────────┘
                         │
                         ▼
              ┌── 支线（第11课）──┐
              │ 贪吃蛇 + 类与二维结构 │
              └────────────────────┘
```

**本班已锁定**

1. 12 次课上完全部 12 个实验，第 11 课与第 12 课都上，不互相挤掉。
2. 第 11 课验收是现场能玩：能动、能吃到一次食物、能撞墙结束。咬自己、不许回头、记分放课后。
3. 第 3 课、第 8 课各只占一次连堂，当堂必须跑完读文件 / 去重，来不及的嵌套循环和 append 改作业。
4. Steam 第 9 课不做复杂字段解析（改作业），把课堂留给认列、replace、转 int，避免第 10–11 课前面积压。

**本课承诺**：零基础学生能独立打开 csv、写出带循环和函数的分析小脚本，并解释自己筛掉了哪些脏数据；第 11 课能交出一条可操作的命令行蛇。

**本课不讲**：pandas、可视化大屏、Web、爬虫、正则、类的继承。

**语法顺序不要改成教材目录。** 学生先会算、会存，立刻面对“表太大不能手敲”，这才引出列表、文件和 for。可以压缩课时，不应当重排成“先讲完 list / dict / str 再做项目”。

## 5. 分课执行稿

每课固定六块：材料、目标、怎么上、实验、验收、下一课接口。主讲课前读本课 + 上一课的接口；助教只带“实验”和“验收”进机房。

### 第 1 课　环境与第一次计算

**对应** `1/` · 实验介绍 Chapters 01 · 教案 `21-L01-env-arithmetic.md`

**材料**

- 必做 notebook：`1/experiment1.ipynb`（5 个任务：认识 IDE、加减留下来、输入计算输出、注释、乘除）
- 参考图：`1/images/`
- 本课不发 csv

**目标**

- 能新建或打开 ipynb，用 Shift+Enter 跑通四则运算
- 能说明：不写 print 时界面往往只露出最后一个结果；重启内核后变量会丢

**怎么上（90 分钟）**

1. 前 15 分钟只做登录/环境彩排，有人打不开不要开讲
2. 界面：四块区域、新建文件夹、Markdown 与 Code 切换
3. `1+1`、`2+9` 先猜后跑；两块加法；重启内核再跑全本
4. print 混用、注释掉一行、乘除

不要开场讲“Python 是什么语言”。开场只问：小学算术能不能让机器代劳。

**当堂验收**：自己的文件里有一行 `print(2+9)` 且有输出。不收书面作业。

**接口**：带着“会运行代码块”来上第 2 课。不必保存算术结果。

**卡点**：点了运行没反应 → 看是否停在 Markdown；重启后数字没了 → 这是教学内容；全角 `＋` 当场对比半角。

### 第 3 课　列表、文件与循环

**对应** `3/` · 实验介绍 Chapters 03 · 教案 `23-L03-list-file-loop.md`

**材料**

- 数据：`3/mobile_game_info.csv`（266 条）
- 学生新建 `experiment3.ipynb`（仓库无现成分析稿）
- 本班不拆周：一次 3 学时连堂上完列表 + 读文件

**目标**

- 能用 `data[i][j]` 取出第 i 行第 j 列
- 能把 csv 读成列表的列表并跳过表头
- 能写出累加评分再除以条数的平均分，评分列经过 `float`

**怎么上（3 学时，约 160 分钟）**

| 分钟 | 内容 |
|------|------|
| 0–15 | 回钩：一行游戏有名字也有评分，几个变量会爆炸 |
| 15–55 | 一条列表、下标取评分、五条嵌套、`[i][j]`；负索引只点“最后一列” |
| 55–70 | 练习：取出样例里某一行的评分 |
| 70–100 | 266 行不能手敲；核对文件；`open` → `reader` → `list`；打印前 5 行与 `len` |
| 100–140 | for 打印 row；跳表头；`float` 累加求平均；故意不 `float` 看报错 |
| 140–160 | 验收 `len(body)` 与平均分；append 改作业 |

`open` 只出现 `r` 与 `encoding='utf-8'`，不讲 15 种 mode。负索引与 append 都课后。

**当堂验收**：`print(len(body))` 与平均分；说不出“第几列是评分”的算未掌握。

**接口**：留下 `header`、`body`、平均分代码。第 4 课直接在同一 notebook 后面写 if。

**卡点**：`FileNotFoundError` 先查工作目录，禁止改去讲别的；表头被算进平均 → 打印第 0 行；中文乱码 → 漏了 encoding。

**补救**：本课未跑通文件的，必须在第 4 课前由助教加一场 45 分钟补实验，否则后续全是空转。

**对应** `5/` · 实验介绍 Chapters 05 · 教案 `25-L05-dict.md`

### 第 6 课　函数入门：抽列与频率表

**对应** `6/` · 实验介绍 Chapters 06 · 教案 `26-L06-functions.md` 第一次课

**材料**

- 数据：`6/mobile_game_info.csv`
- 接着第 5 课 notebook 写，不要另起炉灶重抄循环

**目标**

- 能写出 `def`、参数、`return`（print 在函数里 ≠ 返回了值）
- 能创建抽取任意列的函数、为列表生成频率表的函数
- 能在一个函数里调用另一个函数得到频率表

**怎么上（90 分钟）**

1. 平方函数降温：有来有回，对照 print 与 return
2. 抽列函数；换下标立刻得到名字列或评分列
3. 把第 5 课四步贴进 def
4. 两参数 + 函数调函数
5. 对比：没有函数时 notebook 有多长

平方只为降低恐惧，真正的项目函数是抽列和频数。不要把整节耗在数学函数上。

**当堂验收**：换一个列下标，原函数能出新的频率表。

**接口**：抽列、频数两个函数必须能被第 7、8 课直接调用。

### 第 7 课　函数进阶：默认参数、元组与作用域

**对应** `7/` · 实验介绍 Chapters 07 · 教案 `26-L06-functions.md` 第二次课

**材料**

- 数据：`7/mobile_game_info.csv`（用来调用第 6 课的函数，不是新分析题）

**目标**

- 不把自定义函数命名为 `print` / `list` 等内置名
- 能使用默认参数；能同时返回多个值并拆包（类型是元组）
- 能指出函数内赋值没有改掉外面的同名变量

**怎么上（90 分钟）**

1. 破坏性：把函数命名为 `print` 再调用真正打印
2. 默认参数：列下标默认评分列
3. `return` 两个值、`type` 是 tuple、拆包
4. 函数内 `x = 1`，外面 `x` 仍是旧值

**当堂验收**：拆包两个返回值；能口头指出局部赋值不影响外部。

**接口**：带着可复用的读取 / 抽列 / 频数函数进入第 8 课。第 8 课不再学新语法。

### 第 9 课　处理 Steam 游戏数据（上）：字符串清洗

**对应** `9/` · 实验介绍 Chapters 09 · 教案 `28-L08-steam-clean.md`

**材料**

- 主数据：`9/steam.csv`（约 2.7 万行，先认列再全表循环）

**目标**

- 能打开 steam.csv 并对照 header 说出分析要用的列
- 能用 `replace`、大小写统一清洗分类 / 平台，使 `==` 或 `in` 比较稳定
- 能从带杂质的评价数字段得到整数

**怎么上（3 学时；复杂字段解析改作业）**

字符串方法迟到这里才登场，是因为移动游戏表相对干净。不是“现在开始学字符串”，是“字段拒绝被计算了”。

**当堂验收**：同一列清洗前后各 print 3 行；int 转换成功。认不出列名的不能进入第 10 课。

**接口**：清洗函数或清洗后的列表留给第 10 课。列下标写在 notebook 顶部常量区。

### 第 12 课　从疾病数据认识时间模块

**对应** `12/` · 实验介绍 Chapters 12 · 教案 `31-L11-datetime.md`

**材料**

**目标**

- 全班锁定一种 import 写法（推荐 `from datetime import datetime`）

**接口**：无后续必修课。期末上机：生 csv 上做读取、筛选、频数、平均；可加“统一日期并数某年记录数”。不单独出贪吃蛇算法证明题，蛇只在第 11 课过程分里考“能玩”。
