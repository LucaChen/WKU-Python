# Python 实践课 · 教学内容大纲

| 项目 | 内容 |
|------|------|
| 课程名称 | Python 数据分析入门（实践） |
| 适用班级 | 编程班 · 零基础可入学 |
| 课次 / 学时 | 严格 12 次课，每次 3 学时连堂，合计约 36 学时 |
| 材料目录 | 本目录各 `第XX课-*/` |
| 配套课表 | [`12节课课程安排.md`](/guide/python-schedule) |

本大纲只回答：**每节课要教哪些知识点、练到什么程度、什么不讲。** 课堂怎么拆分钟、卡点怎么处置，见各课 `教案.md`。

---

## 1. 课程目标

学生学完 12 课后，应能：

1. 用 Python 打开 csv，用列表、循环、条件、字典和函数完成读取、清洗、统计。
2. 解释自己筛掉了哪些脏数据，而不是只交一个数字。
3. 用类和二维列表做出一条能玩的命令行贪吃蛇（能动、能吃、能撞墙死）。
4. 用标准库 `datetime` 统一日期格式并比较先后。

**不讲**：pandas、可视化、Web、爬虫、正则、异常处理体系、类的继承。

## 2. 知识点总表（按出场顺序）

语法按项目需要登场，不要改成“先讲完 list / dict / str 再做实验”。

| 课 | 主题 | 当堂必须讲清的知识点 |
|----|------|----------------------|
| 1 | 环境与第一次计算 | Jupyter 代码块与内核；表达式；`print`；`#` 注释；四则运算 |
| 2 | 变量与类型 | 赋值与覆盖；命名规则；`int` / `float` / `str`；`int()` `float()` `str()`；字符串拼接；`TypeError` |
| 3 | 列表、文件、循环 | 列表与正负索引；嵌套列表 `data[i][j]`；`open` / `csv.reader`；`for`；跳表头；`float` 再运算 |
| 4 | 条件筛选 | 比较运算与布尔值；`if` / `elif`；`==` `!=`；`and` / `or` |
| 5 | 字典与频数 | 键值对；`in`；`d[k] = d[k] + 1`；`KeyError`；百分比 |
| 6 | 函数入门 | `def`；参数；`return`（≠ `print`）；函数调函数 |
| 7 | 函数进阶 | 不要覆盖内置名；默认参数；多返回值与元组拆包；全局 / 局部作用域 |
| 8 | 综合分析 | 清洗口径；去重策略；复用旧函数；嵌套循环（外层类型、内层行） |
| 9 | Steam 清洗 | 换表先认列；`str.replace`；大小写统一；去杂质再 `int` |
| 10 | 年份与档位 | 字符串切片；档位化；复用频数函数；可读摘要 |
| 11 | 贪吃蛇 | `range`；二维列表；`class` / 实例 / `__init__`；主循环 |
| 12 | 日期时间 | `import`；`datetime`；`strptime` / `strftime`；时间先后与时长 |

三条学期级能力绳（每课都要勾回来）：

1. **值有类型**：看起来像数字的字段经常是字符串，要算先转换。
2. **表是嵌套列表**：行是内层列表，列是下标。
3. **先清洗，再谈平均分**：口径说不清，数字再好看也不算掌握。

## 3. 分课知识点

### 第 1 课　环境与第一次计算

**材料**：`第01课-环境与第一次计算/`

| 类别 | 内容 |
|------|------|
| 核心知识点 | 1. Jupyter：代码块、Markdown 块、Shift+Enter、保存 ≠ 内核里的变量还在<br>2. 重启内核后变量会消失<br>3. 表达式会算出值；不写 `print` 时界面往往只露出最后一个结果<br>4. `print(...)` 用来主动输出<br>5. `#` 注释让某行不执行<br>6. 加减乘除：`+ - * /`，半角符号 |
| 能力要求 | 能新建或打开 ipynb / 运行 `experiment.py`；能写出 `print(2+9)` 并看到输出 |
| 当堂不讲 | Python 语言史；多行写成一行（分号）；csv |
| 前置 | 无 |

### 第 2 课　变量、类型与字符串

**材料**：`第02课-变量类型与字符串/`

| 类别 | 内容 |
|------|------|
| 核心知识点 | 1. 赋值 `=`：给结果起名字，方便下次再用<br>2. 二次赋值会覆盖旧值<br>3. 命名规则：不能数字开头、不要用关键字<br>4. `int` 整数、`float` 浮点数、`str` 字符串<br>5. `3 / 2` 的结果是 `1.5`（浮点）<br>6. `int(3.9)` 是截断成 3，不是四舍五入<br>7. `int()` / `float()` / `str()` 类型转换<br>8. 字符串用引号；`+` 拼接两段文字<br>9. 数字和字符串不能直接相加，会 `TypeError` |
| 能力要求 | 能解释覆盖后旧值在哪；能说明 `int(3.9)`；能读懂 `"1"+1` 的报错 |
| 当堂不讲 | `+=` 只口头对照；长字符串格式化；`input()` |
| 前置 | 会运行代码块 |

---

### 第 3 课　列表、文件与循环

**材料**：`第03课-列表文件与循环/` · `mobile_game_info.csv`

| 类别 | 内容 |
|------|------|
| 核心知识点 | 1. 列表：一行游戏的多个字段装在一个列表里<br>2. 正索引取第 n 列；负索引取最后几列（点到即可）<br>3. 嵌套列表 = 一张表；`data[i][j]` 是第 i 行第 j 列<br>4. `open(path, encoding="utf-8")` 只是打开文件<br>5. `csv.reader` + `list(...)` 才读成表<br>6. 第 0 行通常是表头，计算前要跳过<br>7. `for row in body:` 对每一行做同一件事<br>8. 评分列是字符串，必须 `float` 才能求平均<br>9. `len(body)` 是行数 |
| 能力要求 | 能指出评分是第几列；能打印 `len(body)` 和全表平均分 |
| 当堂不讲 | `open` 的各种 mode；`append` 改作业；pandas |
| 前置 | 会变量与 `float` 转换 |

---

### 第 4 课　条件判断与筛选

**材料**：`第04课-条件判断与筛选/`

| 类别 | 内容 |
|------|------|
| 核心知识点 | 1. 比较运算 `== != > >= < <=` 的结果是布尔值 `True` / `False`<br>2. `if`：条件成立才处理这一行<br>3. `!=` 找“不是安卓”<br>4. 文件里的 `'TRUE'` 是字符串，不要和布尔 `True` 混比<br>5. `and`：同时满足；`or`：满足其一（不是“只能选一个”）<br>6. 组合条件：例如“角色扮演或策略，且非安卓”<br>7. `if / elif / else` 多分支打标<br>8. 三类计数之和必须等于总行数 |
| 能力要求 | 能写出组合条件并算子集平均分；能口头说清留下谁、扔掉谁 |
| 当堂不讲 | 三元表达式；复杂嵌套 if 理论 |
| 前置 | 会 `for` 遍历 `body`，知道评分列下标 |

### 第 5 课　字典与频数

**材料**：`第05课-字典与频数/`

| 类别 | 内容 |
|------|------|
| 核心知识点 | 1. 字典由键值对组成：`{类型: 数量}`<br>2. 用键取值：`d[key]`<br>3. `in` 检查键是否存在，避免 `KeyError`<br>4. 频数四步：建空字典 → 循环 → 键不在则置 0 → 对应值 +1<br>5. 百分比 = 计数 / 总数 × 100，注意不要用整数除法<br>6. （选做）`min` / `max`、下载量分箱 |
| 能力要求 | 能做出类型频率字典和百分比，keys 应是类型名 |
| 当堂不讲 | 字典推导式；`collections.Counter` 作为必会内容 |
| 前置 | 会 `for` + `if` |

### 第 6 课　函数入门

**材料**：`第06课-函数入门/`

| 类别 | 内容 |
|------|------|
| 核心知识点 | 1. 函数是调用时才运行的代码块：`def` 是定义，不是执行<br>2. 参数：调用时传进去的数据<br>3. `return` 把结果交回去；函数里 `print` 不等于返回了值<br>4. 抽列函数：参数是列下标，返回这一列<br>5. 频数函数：把第 5 课四步收进 `def`<br>6. 两个参数的函数<br>7. 函数里调用另一个函数（抽列后再做频率） |
| 能力要求 | 换一个列下标，原函数能出新的频率表 |
| 当堂不讲 | `*args` / `**kwargs`；lambda；作用域（放到第 7 课） |
| 前置 | 第 5 课四步频数已亲手写过 |

### 第 7 课　函数进阶

**材料**：`第07课-函数进阶/`

| 类别 | 内容 |

| 能力要求 | 能拆包两个返回值；能指出函数内赋值没有改掉外部变量 |

## 4. 知识点依赖

```text
第1课 表达式/print
  → 第2课 变量/类型
    → 第3课 列表/csv/for
      → 第4课 if/and/or
        → 第5课 字典/频数
          → 第6课 def/return
            → 第7课 默认参数/元组/作用域
              → 第8课 综合清洗（阶段验收）
                → 第9课 字符串方法
                  → 第10课 切片/档位
                    → 第12课 import/datetime
              → 第11课 二维列表 + class + 主循环
```

第 11 课依赖第 6–7 课的函数和第 3 课的嵌套列表，不依赖 Steam。第 12 课接第 9–10 课的“字段要先洗才能算”，不依赖贪吃蛇。
