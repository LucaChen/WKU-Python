# 课次 L17 自定义 Tool 与 MCP 接入

**对应阶段** 阶段三 · 任务二 2.1+2.2 / 15分

**建议学时** 3

## 目标

**知识目标**

1. 写出 ArgsSchema / ResultSchema
2. 异常隔离成错误文本
3. MCP 握手列出 Tools 与 Resources

**能力目标**

1. 能 export_function_schema
2. 能解释 stdio 握手不等于已经调用了工具

**素养目标**

1. 把模型当不可靠组件：接口、Schema、熔断、溯源缺一不可

**前置准备**

1. 第 16 课 Schema

## 当堂不讲

- 真实 npx MCP 进程管理、SSE 重连的工程细节

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–20 | Tool 契约与 Function Calling JSON |
| 20–55 | 短 SKU / 未知 SKU 两次隔离 |
| 55–80 | MCPClient.handshake 读元数据 |
| 80–90 | 15 分评分对照 |

## 实验

必做：讲义案例 + 综合练习 P1。破坏性：超时、校验失败、死循环、越界提问（按课次出现）。

## 卡点

| 现象 | 处置 |
|------|------|
| 校验失败直接 raise | 必须返回 ResultSchema(ok=False) |
| 把业务异常当成 Python 崩溃 | 未知 SKU 也走 error 字段 |
| 只打印 server 名 | 必须列出 tools 与 resources 清单 |

## 当堂验收

导出 Function Calling Schema；参数/业务异常隔离；MCP 握手读出 Tools 与 Resources。

## 接口

教学运行时：`agent_lab/`。验收：`python3 experiment.py`。
