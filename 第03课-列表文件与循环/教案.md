# 课次 L03 列表、文件与循环

**对应源章** Ch03

**建议学时** 4（必须拆成两次 90 分钟，中间不要开新概念）

## 目标

**知识目标**

1. 了解列表、下标、负下标、嵌套列表
2. 了解 open、encoding、csv.reader 各自走到哪一步
3. 了解 for 循环变量每一轮会被重新绑定

**能力目标**

1. 能用 data[i][j] 取出第 i 行第 j 列
2. 能把 mobile_game_info.csv 读成列表的列表并跳过表头
3. 能写出累加评分再除以条数的平均分，评分列经过 float

**素养目标**

1. 体会"手敲 266 行"不可行，接受文件读取是分析的前提而不是高级技巧

**前置准备**

1. 掌握变量与 float 转换
2. csv 已放到与 notebook 约定的相对路径
3. 教师已打开文件确认分隔符是逗号、编码是 UTF-8

## 小节合并

第一次课（2 学时）：列表存一行 → 正负索引 → 五条样例嵌套 → [i][j]。不碰文件。

第二次课（2 学时）：open 对象长什么样 → reader 成表 → 打印前 5 行与 len → for 打印 row → 全表平均分。append 拓展放第二次课末尾 10 分钟或作业。

open 的 mode 全表不讲。只出现 r 与 encoding='utf-8'。

## 时间盒（2×90 分钟）

**第一次**

| 分钟 | 内容 |
|------|------|
| 0–10 | 回钩：一行游戏有名字也有评分，几个变量会爆炸 |
| 10–40 | 一条列表、下标取评分、改一个元素 |
| 40–75 | 五条嵌套、[2][2]、负索引只点"最后一列" |
| 75–90 | 练习：取出明日方舟那一行的评分（样例里写死） |

**第二次**

| 分钟 | 内容 |
|------|------|
| 0–15 | 问题：266×7 不能手敲；核对文件是否在 |
| 15–40 | open → reader → list；打印类型与前 5 行 |
| 40–70 | for 打印 row；跳表头；float 累加求平均 |
| 70–80 | 故意不 float，读报错 |
| 80–90 | 收束：表 = 列表的列表；布置 append 选做 |

## 实验

必做：一行列表、嵌套取格、读 csv 前 5 行、for 打印、全表平均、忘记 float。选做：append + sum/len。

## 怎么串

本课是主脊从"会算"转到"会处理表"的关节。讲完下标立刻说：以后所谓抽一列，就是循环里反复写 row[2]。第二次课的平均分必须用真文件，不要只用五条样例过关——样例过关只证明循环语法，不证明路径与编码。

## 卡点

| 现象 | 处置 |
|------|------|
| FileNotFoundError | 先 pwd/看工作目录，禁止改去讲别的 |
| Excel 另存 xlsx | 退回 csv |
| 表头被算进平均 | 打印 android[0] 让学生自己看见列名 |
| 评分列下标讲错 | 全班一起 print header，把下标写在黑板 |
| 中文乱码 | encoding 漏了；不要开始讲系统代码页 |

## 当堂验收

第二次课结束前，助教抽查：print(len(body)) 与平均分。说不出"第几列是评分"的算未掌握，即使数字碰巧对。

## 接口

留下：header、body（或 android 这类名字）、平均分代码。L04 直接在同一 notebook 后面写 if。
