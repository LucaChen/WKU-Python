# 第10课-年份切片与摘要

**主题**：年份切片与摘要

**当堂验收**：年份键是四位年；档位频率字典里能看到 100000+ 这类键；摘要是人话而不是只 dump 字典。

**说明**：课堂讲义与本课数据同目录；课后练习使用题面指定的文件。从该文件夹启动内核。

课堂讲义与 `steam.csv` 同目录；课后练习使用 `steam_sample.csv`。档位规则：取首位，其余补 0，再加号。打开 CSV 使用 `encoding="utf-8-sig"`。案例只演示前 5 行年份与档位，不要把全部年份键当成讲义答案。
