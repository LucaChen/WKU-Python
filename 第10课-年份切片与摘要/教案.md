# 课次 L09 年份、切片与摘要

**对应源章** Ch10

**建议学时** 3

## 目标

**知识目标**

1. 了解字符串与列表一样可以切片
2. 了解档位化（124534 → 100000+）是为了频率表可读，不是为了精确算术

**能力目标**

1. 能抽出发行年并做频率
2. 能按源讲义规则把好评数变成档位字符串
3. 能复用 L06 频数函数统计开发者

**素养目标**

1. 摘要输出要让人读得懂：数字旁边有单位或说明，而不是只 dump 字典

**前置准备**

1. L08 评价数字段已能转成数字或纯数字字符串
2. 频数函数可调用

## 小节合并

三段：年份 → 切片档位 → 开发者频数。第四小节"打印特定开发者"默认作业，课堂只演示一次格式化。

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–10 | 回钩：L08 的数字现在可以比较，但 10 万个不同评价数做不出表 |
| 10–35 | 发行年抽取与年份频率 |
| 35–70 | 切片取首位、其余补 0、加号；对照 3318 → 3000+ |
| 70–85 | 开发者频数 Top 若干 |
| 85–90 | 演示一行摘要；作业按此格式交 |

## 实验

必做：年份频率、切片档位、开发者频数。选做：开发者摘要函数。

## 怎么串

切片系统课放在这里，是因为 L03 只用过"前 5 行"这一种切片。强调：档位规则是约定，全班必须同一规则，否则频率不能比。开发者频数是故意的重复——学生应感到"又是那四步"，从而相信函数值得写。

## 卡点

| 现象 | 处置 |
|------|------|
| 对 int 做切片 | 先 str() |
| 位数不同的数补 0 补错 | 用讲义三个例子当测试用例 |
| 年份字段含月日 | 只取年，指定切片或 split，全班一种写法 |
| Top 排序想用 pandas | 不允许；用手写或 sorted 简介，不展开 key 理论 |

## 当堂验收

档位频率字典里能看到 100000+ 这类键；年份键是四位年。

## 接口

路径 A 下一课转贪吃蛇，明确宣布主线数据课到此暂停。路径 B 下一课接 datetime 或自选 Steam 问题。
