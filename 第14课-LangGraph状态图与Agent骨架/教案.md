# 课次 L14 LangGraph 状态图与 Agent 骨架

**对应阶段** 阶段一 · 前置理论

**建议学时** 3

## 目标

**知识目标**

1. 用 reducer 声明状态如何合并
2. 画出 Node / Edge / 条件边
3. 用 recursion_limit 与 MemorySaver 处理循环与多轮

**能力目标**

1. 能手写 agent-tool-finalize 闭环
2. 能解释 messages 为何是累积而 user 是覆盖

**素养目标**

1. 把模型当不可靠组件：接口、Schema、熔断、溯源缺一不可

**前置准备**

1. 第 13 课探活通过

## 当堂不讲

- LangGraph 云部署、子图、Human-in-the-loop 完整产品化

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–15 | Agent = 状态图：对照流程图 |
| 15–55 | channels / add_node / add_conditional_edges |
| 55–80 | Checkpointer 多轮 + 熔断演示 |
| 80–90 | 收束：下一课把图嵌进 OpenClaw |

## 实验

必做：讲义案例 + 综合练习 P1。破坏性：超时、校验失败、死循环、越界提问（按课次出现）。

## 卡点

| 现象 | 处置 |
|------|------|
| 条件边走错 | router 返回的标签必须出现在 mapping 里 |
| 死循环 | 课堂先把 recursion_limit 调到 3 看报错，再改边 |
| 次轮丢掉首轮消息 | messages 必须用 add_messages，不能 overwrite |

## 当堂验收

条件边走出 agent→tool→finalize；Checkpointer 累积 messages；recursion_limit 触发熔断。

## 接口

教学运行时：`agent_lab/`。验收：`python3 experiment.py`。
