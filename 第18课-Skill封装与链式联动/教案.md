# 课次 L18 Skill 封装与链式联动

**对应阶段** 阶段三 · 任务二 2.3 / 20分

**建议学时** 3

## 目标

**知识目标**

1. 单工具精准命中
2. A 的 Pydantic 输出无缝注入 B
3. 模糊指令失败后自修正

**能力目标**

1. 能读懂 quote_skill 的数据流
2. 能指出自愈前后的 first_error

**素养目标**

1. 把模型当不可靠组件：接口、Schema、熔断、溯源缺一不可

**前置准备**

1. 第 17 课 Tool

## 当堂不讲

- 多 Agent 辩论、异步并发编排

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–15 | Skill ≠ Tool：组合与清洗 |
| 15–50 | 基础命中 + 进阶双工具 |
| 50–80 | self_correct_quote 对抗“小部件X” |
| 80–90 | 20 分评分对照 |

## 实验

必做：讲义案例 + 综合练习 P1。破坏性：超时、校验失败、死循环、越界提问（按课次出现）。

## 卡点

| 现象 | 处置 |
|------|------|
| 第二步用手改数字 | 必须用第一步校验后的字段 |
| 自愈直接从别名开始 | 高难要求先失败再修，attempts==2 |
| 库存不足仍报价成功 | 本课库存表以 STOCK 为准，未知 SKU 必须失败 |

## 当堂验收

单工具命中、双工具串行流转、模糊指令自愈三例全部成功。
