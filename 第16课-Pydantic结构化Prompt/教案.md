# 课次 L16 Pydantic 结构化 Prompt

**对应阶段** 阶段二 · 任务一 1.2 / 15分

**建议学时** 3

## 目标

**知识目标**

1. 用 BaseModel/Field 生成 JSON Schema 并写入 Prompt
2. 扁平、嵌套、自定义校验器三档都跑通
3. 对抗脏数据时拦截而不是静默 NaN

**能力目标**

1. 能解释 phone 去空格
2. 能查出 total 与明细不一致
3. 能把 ￥1,299.00 归一成 1299.0

**素养目标**

1. 把模型当不可靠组件：接口、Schema、熔断、溯源缺一不可

**前置准备**

1. 第 15 课握手通过

## 当堂不讲

- Pydantic v1、dataclass 替代方案

## 时间盒（90 分钟）

| 分钟 | 内容 |
|------|------|
| 0–15 | Schema 即契约，不是事后正则 |
| 15–55 | UserProfile / TicketAnalysis 两档演示 |
| 55–80 | DirtyAmount 与“免费送”拦截 |
| 80–90 | 15 分评分对照 |

## 实验

必做：讲义案例 + 综合练习 P1。破坏性：超时、校验失败、死循环、越界提问（按课次出现）。

## 卡点

| 现象 | 处置 |
|------|------|
| 把校验写在 Prompt 里却不跑 model_validate | 模型输出必须再走一遍 Schema |
| 嵌套 list 忘记子模型 | LineItem 要单独定义 |
| 校验器 mode 不对 | 归一化脏字符串用 mode='before' |

## 当堂验收

三级梯度：扁平用户、嵌套工单、脏金额归一化与对抗拦截全部通过。
