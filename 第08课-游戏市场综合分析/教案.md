# 课次 L07 游戏市场综合分析

**对应源章** Ch08

**建议学时** 4（两次 90 分钟，是学期验收不是新语法周）

## 目标

**知识目标**

1. 了解数据清洗包含纠错、去重、按分析口径筛选
2. 了解嵌套循环：外层类别、内层行

**能力目标**

1. 能封装读取函数并在同一文件里完成去重
2. 能写清语言与平台口径（留下哪一侧）并执行
3. 能用类型频率或平均下载量回答"哪类更吸引用户"

**素养目标**

1. 拒绝在脏数据上发布结论；清洗规则写在 notebook 第一格

**前置准备**

1. 抽列、频数、for、if 均能独立写
2. 教师提前在数据里确认至少存在一组重复名（源材料用 Phigros 举例）

## 小节合并

第一次课：读取函数 → 找重复 → 去重（明确留哪一条）。

第二次课：语言/平台筛选 → 类型吸引力 → 嵌套循环特征。源标题"删除英语应用"与"只分析英语游戏"并存，开课投影一行口径，全班统一，例如："本班保留安卓且名称视为中文市场的条目"——以教师选定为准，但必须可检查。

## 时间盒（2×90 分钟）

**第一次**

| 分钟 | 内容 |
|------|------|
| 0–10 | 宣布：本课不学新语法，把旧积木组装 |
| 10–30 | 读取函数，核对 len |
| 30–75 | 字典数名字；打印 Phigros 两行差异；决定保留规则 |
| 75–90 | 去重后 len 下降；学生写下规则 |

**第二次**

| 分钟 | 内容 |
|------|------|
| 0–25 | 按口径筛选；筛选前后行数 |
| 25–60 | 类型与下载量/评分；复用频数函数 |
| 60–80 | 嵌套循环：对每个热门类型再看一条特征 |
| 80–90 | 每人三句话结论：口径、行数变化、哪类更吸量 |

## 实验

必做：读取封装、重复检出、去重、口径筛选、类型分析、嵌套循环。无选做；来不及的嵌套循环放到作业，不可删去重。

## 怎么串

这是 P1–P4 的汇流。教师少讲、多问："这一步用的是第几课的积木？" 去重用字典（L05），筛选用 if（L04），平均用 for+float（L03），封装用 def（L06）。嵌套循环是本课唯一略新的控制结构，用"外层类型列表、内层逐行"画两个圈就够。

## 卡点

| 现象 | 处置 |
|------|------|
| 去重删光或一行不删 | 先 print 重复样例，再写算法 |
| 在循环里删正在遍历的列表 | 改为建新列表 |
| 口径口头与代码相反 | 第一格重写，不以数字漂亮为准 |
| 文件散成 8 个格子互不相干 | 要求从上到下 Restart and Run All |

## 当堂验收

Restart and Run All 能出：清洗后行数、类型表、三句话结论。这就是阶段作业的课堂版。

## 接口

清洗后的数据集若还要做 Steam，不必沿用——L08 换文件。本课 notebook 作为阶段提交物归档。

- 路径 B 可加一小时让学生换一个自选问题（最贵、最高分）。
- 路径 C 嵌套循环可缩短，把时间留给后面的蛇。
